# DRINKA by Kai Bobba · sitio web

Matcha, taro, tés y café en Milagro, Ecuador.

**Ver el sitio:** https://elohim-desing-ec.github.io/drinka-web/

## Cómo editar

Todo lo del negocio está al inicio de `script.js`, en la parte **EDITA AQUÍ**:

- `DRINKA`: WhatsApp, redes, dirección y horario.
- `MENU`: categorías, bebidas, precios, favoritos y descripciones.

Las fotos de las bebidas van en `PNG/` (grandes) y `assets/vasos/` (miniaturas `-mini.webp`), con el mismo nombre que el campo `foto`.
